# Finlo Wallet – Fintech App Wireframe

## Overview

A professional low-fidelity mobile wireframe for a fictional fintech application called Finlo Wallet. The project focuses on creating a simple and intuitive user flow for authentication, checking balance, sending money, reviewing payments, and viewing transaction history.

## Internship

CodTech IT Solutions — UI/UX Internship

## Task

Task 2 — Wireframing for a Fintech App

## Tool Used

- Figma
- Figma Make
- PDF

## Screens Included

1. Login / Sign Up
2. Home / Dashboard
3. Send Money
4. Transaction Review
5. Payment Success
6. Transaction History

## User Flow

Login → Home → Send Money → Transaction Review → Payment Success → Transaction History

## UX Considerations

- Clear navigation and hierarchy
- Simple low-fidelity layout
- Consistent mobile screen structure
- Clear primary and secondary actions
- Accessible labels and interaction states
- Positive and negative transaction states
- Minimal visual complexity
